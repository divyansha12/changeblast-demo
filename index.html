npm package demonstration

Know what your code changes affect.

This public demo installs ChangeBlast as a development dependency and uses it to trace source changes to the tests that depend on them.

View npm package View source
Install and run
$ npm install --save-dev changeblast
$ npm run analyze
$ npm run analyze -- --explain
